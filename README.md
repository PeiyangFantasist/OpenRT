# OpenRT

**Return Curve Advise for Individual Investors**

公募基金滚动持有收益与每日定投研究工具。iOS 液态玻璃风格，支持电脑与手机。

- 网站：<https://peiyangfantasist.github.io/OpenRT/>
- 仓库：<https://github.com/PeiyangFantasist/OpenRT>

## 使用

输入六位基金代码，按已公布的每日历史净值计算。支持任意代码，前提是天天基金提供该基金的单位净值序列；不支持货币基金的万份收益。常用基金优先读取每日更新的站点缓存，其他基金通过天天基金官方 JavaScript 资源读取，并在浏览器缓存六小时。没有使用公共 CORS 代理。

RT-α 的横轴是起投日期，纵轴为固定持有期限后的区间收益率。α 最小单位为自然日，可自定义 1–3,650 天，快捷项为 30 / 90 / 180 / 365 / 730 / 1,095 天。显示完整样本数、非重叠窗口数、亏损率（含零收益）、均值、中位数、标准差、分位数与极值，并可导出 CSV。

每日定投包含定投起始日、终止日、每日金额和收益结算日，可设置简化申购及赎回费。输出累计投入、结算价值、利润、区间收益率和成本 / 资产曲线。曲线支持触摸、鼠标及键盘方向键查看。

## 计算规则

`Rα(T) = S(E(T+α)) / S(T) - 1`。T 是一个净值所属日，E 为目标日当天或之后首个可用净值日；向后容差 10 个自然日，超过则剔除。未到期窗口不参与统计。“亏损率”表示历史 P(R≤0)，包括零收益，是历史样本比例，不能解释为未来亏损概率。高度重叠窗口不是独立样本；非重叠窗口数也不保证统计独立。

S 是分红 / 拆分事件近似调整指数：普通日期使用单位净值精确比值，仅在明确的事件日借助上游公布的日增长率桥接。该事件涨幅可能四舍五入，因此不是认证的官方复权净值。累计净值不直接当作复权净值。事件数据不完整时整段回退未复权净值并警告。详见 [数据与复权政策](docs/data-sources.md)。

定投仅在区间内有净值记录的日期投入，包含起止日；没有净值的日期跳过且不补投。结算日无净值时向前取最近已公布净值，超过最新净值日期会被拒绝。以 S 计算研究份额并假设分红再投资；不还原真实申购暂停、额度、交易确认、分红再投资确认日、税费或份额舍入。申购费按投入金额的指定比例扣除，赎回费按资产价值的指定比例扣除，是简化模型。收益率为累计收益率，非 XIRR 或年化收益。

QDII 可能延后披露。始终区分净值所属日期、数据抓取时间和浏览器时间，不填造尚未公布的净值。没有历史发布时间数据，不能用净值所属日重建当时实际可得信息或可成交价格。

## 数据更新与部署

GitHub Pages 托管静态 React 网站，无常驻服务器费用。`.github/workflows/pages.yml` 在推送、手动触发及每天北京时间 **09:20 / 19:20 / 23:20** 运行：恢复已验证缓存 → 测试与类型检查 → 顺序读取上游 → 构建 → 部署。GitHub 调度可能延迟，不是精确 SLA；公开仓库长期无活动时，GitHub 可能暂停定时工作流，需要在 Actions 页面重新启用。

默认更新 `000001,161725,019454,110011,005827,001632` 六只基金。可在 `scripts/update-data.ts` 修改列表，或设置工作流环境变量 `OPENRT_FUND_CODES`（最多 30 只，逗号分隔）。新代码不必等待此列表更新，浏览器可以按需查询。

更新失败时保留上一份数据及原抓取时间；初次部署的六份真实快照保存在 `data/bootstrap/`，所属日期与抓取时间不会被伪装成最新。全失败或缺少缓存会产生工作流警告，已有缓存仍可发布；页面会显示旧缓存状态。可查看站点 `data/status.json` 获取各基金更新状态。没有缓存且数据源不可达时明确报错。

GitHub Actions 使用仓库内置的 `GITHUB_TOKEN` 部署；仓库与部署产物不含用户密钥。定时缓存通过 Actions Cache 保存，不会持续向主分支提交净值文件。

## 本地开发与验证

需要 Node.js 24。在项目根目录运行：

```sh
npm ci
npm test
npm run typecheck
npm run update-data
npm run dev:pages
npm run build:pages
npm run preview:pages
```

开发地址为 `http://127.0.0.1:5173/OpenRT/`。基础路径默认 `/OpenRT/`，使用其他地址可设置 `OPENRT_BASE_PATH=/` 后构建。`npm run update-data` 需要联网；金融计算和解析测试使用固定数据，不依赖上游。

主要文件：`lib/analytics.ts` 计算，`lib/fund-data.ts` 数据解析，`lib/fund-client.ts` 浏览器读取与缓存，`app/page.tsx` 页面，`app/components/charts.tsx` 图表，`app/globals.css` 样式。保留的 Vinext / Sites 配置可供之后迁移到服务端托管；当前线上运行由 `vite.pages.config.ts` 的 GitHub Pages 静态构建发布。

## 来源、授权与边界

来源为东方财富 / 天天基金公开的历史资源，接口无需 API Key，但不是获得服务保障或历史数据再分发许可的正式免费 API。项目标明来源、保留时效信息并控制更新频率。开源程序与第三方数据的权利分开；正式商业运营或扩大公开数据服务前应取得数据权利人的明确许可，或替换为已授权供应商。

本工具用于历史研究与个人规划。可选Agent提供基于工具结果的条件化分析与建议，不执行买卖、不保证收益，也不替代专业判断。历史表现、单一路径、幸存者偏差、样本相关性和基金策略变化限制外推；投资决定需要结合基金公告、实际费用与个人风险承受能力。

## 界面与日期

主界面按窗口高度分配空间：顶部基金查询，中间 RT 主曲线，下方四个摘要指标，底部胶囊导航切换 RT / 定投 / 对比 / 分析 / 个人。详细收益密度、分位数、标准差和极值在“统计分析”弹窗内。收益密度使用连续高斯 KDE 曲线，以 0% 分界，正收益红色、负收益绿色；支持鼠标、触控及键盘查看收益位置、每 1 个百分点的密度与原样本累计数量/占比。亏损率仍按原始完整窗口计数，不由平滑曲线积分替代。界面支持纯白 / 纯黑主题，卡片与控件透明；单基金涨跌为红 / 绿，对比 B 使用蓝 / 黄；其余文字随主题显示为黑 / 白。布局间距使用 4 / 8 / 16 / 24 px。

副标题位于 OpenRT 下方，使用本地 JetBrains Mono 字体。搜索栏和底部导航使用 [apple-liquid-glass-webgl](https://github.com/Oliverrr2424/webgl-apple-liquid-glass) 2.6.0（MIT，© 2026 Oliver Nemo）渲染玻璃边缘折射与高光，视觉与动效亦参考 [liquidGL](https://github.com/naughtyduk/liquidGL)。玻璃背景采样固定为当前主题的纯白或纯黑底色，避免 DOM 背景重绘把已折叠的说明文字绘入导航。最多增强两个可见表面，限制像素密度，不持续绘制；WebGL 不可用时保留 CSS 透明材质。许可证随站点发布于 [third-party-notices.txt](public/third-party-notices.txt)。按钮和玻璃表面有随鼠标及触控平滑移动的反光，弹窗有打开与关闭动画；系统减少动态效果偏好会关闭装饰动画，减少透明度偏好使用主题底色。算法帮助按主题和小节切换，使用本地 KaTeX 渲染 LaTeX，含变量解释、算例和数据局限。

页面读取北京时间日期，每 30 秒检查一次换日；可见时每 15 分钟检查数据缓存，换日时尝试读取官方源。每次 α、日期或净值变化都会重新计算 RT。窗口必须同时满足 T+α 不晚于今日、所选终点净值已公布且不晚于今日；明天没有新净值时仍不会虚构到期收益。页面显示今日、最新净值日和最晚完整起投日。自动刷新保留当前定投计划，不会擅自改动用户输入。

上游超时、限流及服务器错误会有限重试（最多两次额外尝试）；失败快照保留原抓取时间并标记旧缓存，浏览器可再尝试读取官方源。

## 双基金对比

底栏“对比”切换后，可分别查询 A / B 两支基金，并选择 RT 或定投比较。RT 使用共同持有期，定投使用共同日期、金额与简化费率。仅在两基金都实际公布净值的日期交集上计算，统一起止日期和现金流；不补造价格，不把较短基金的成立前历史纳入比较。

对比主图以颜色和粗细区分基金：A 使用正收益红色、负收益绿色的粗线，B 使用正收益蓝色、负收益黄色的细线；定投同样按相对共同成本的收益符号着色，成本线保持主题色。对应的收益数字使用各自配色。下方并列指标的较优项使用黑 / 白主题色粗边框，左上角显示倾斜黑体 “WIN!” 标记：A 为红色，B 为蓝色；主要指标数值加粗。非正收益比例与标准差较低为优，收益及分位数较高为优；成本、费用和样本数量不做投资优劣排名，持平和缺失值不作标记。它不是综合基金评级，跨币种份额未做汇率折算。

详细比较在“统计分析”弹窗中分为收益指标、分位与波动、收益密度。两支基金的连续 KDE 曲线均支持鼠标、触控和键盘查看：A 在 0% 两侧使用绿 / 红粗线，B 使用黄 / 蓝细线，提示中的累计数量及占比来自原样本。平滑带宽与高斯尾部只帮助观察历史形状，不表示独立样本或未来概率；算法帮助包含密度、带宽和面积解释。单基金和比较模式分别保留输入。


移动端进一步精简：已选的对比基金通过“更改”弹窗调整，定投参数通过“定投设置”调整。窄屏保留核心摘要，其余指标在统计分析查看；每项旁的 ⓘ 展开说明，备注不常驻首屏。使用用户提供的 RT 标志，副标题随屏宽放大，主指标标题与数值加粗。输入框避免小字自动放大，帮助切换小节回到内容顶部。


## 分析：统计与组合

分析栏内使用“统计 / 组合”一级切换，共享最多12只基金、整体历史窗口、日/周/月频与年化因子。默认MAX，支持1/3/6月、1/3/5年和自定义日期。按实际共同估值日取交集后才计算简单收益；不插值、不填充、不使用窗口结束日之后的净值。每只基金的窗口外、非共同日及降频排除量可展开查看。估值日与历史真实披露日不能混同。

统计包括区间累计、单期均值/中位数、算术与样本几何年化、正负零频率、样本标准差、波动及最大回撤、密度、ACF（1–60阶）和可选Ljung–Box检验。收益Pearson矩阵使用同一组共同样本，零方差为N/A；不会用净值水平算资产相关。

组合默认不做空、不加杠杆、权重和为1，最低样本数max(30,3×资产数)。MEF枚举可行资产子集求二次规划，含MVP及上半有效前沿；ERC坐标下降并检验原始样本的风险贡献份额误差≤10⁻⁶；高级恰好四项偏好，分别为收益、方差、CVaR95和集中度，提供尺度归一化与重置。CVaR从组合损失计算，不线性相加单基金CVaR；平滑优化后验证原目标的全局对偶间隙≤5×10⁻⁴。失败不输出最优权重。病态协方差的对角正则明确披露。

结果统一提供权重、风险贡献、样本期望年化、波动、样本内回测回撤、约束和收敛状态，并可查看组合RT-α。分别计算初始配置后持有、每个共同估值日再平衡和月末再平衡。无交易成本；权重由同一窗口估计，属于样本内拟合，不能宣称为历史当时可执行的样本外策略。年化因子默认252/52/12，用户可调整；样本几何年化使用观测期数，不是日历CAGR。

算法固定版本 `analysis-1.0.0`，资产排序、迭代和等价解规则确定；数据/参数指纹随结果显示。窗口筛选和统计为纯函数；优化在独立Web Worker运行，参数改变取消旧任务。共享净值缓存与计算结果缓存，切换统计/组合不重复读取净值。

模块：`lib/analysis-statistics.ts`、`lib/portfolio-optimizer.ts`、`lib/analysis-worker.ts`，组件为`WindowSelector`、`AnalysisWorkspace`及`AnalysisVisualizations`。测试包含解析解MVP、对角协方差ERC、两资产稠密独立搜索及SciPy SLSQP/HiGHS预计算参考值；运行时不依赖Python。

## 个人、收藏与Agent

“个人”支持本机头像/用户名、最近100只唯一查看基金、收藏和技术文档。再次查看会前移，后台刷新与AI工具读取不算浏览。原快捷基金及别名自动迁移为收藏；从收藏可打开RT、定投或指定对比A/B。资料与聊天文本只存本机，不是跨设备账号。

“我的Agent”支持浏览器直连兼容Chat Completions工具调用的HTTPS API（本机HTTP可用localhost/127.0.0.1）。默认DeepSeek；填入自己的模型和API Key。服务必须支持浏览器CORS；官方DeepSeek预检已验证。密钥默认只在当前页内存中，可自行勾选本机记住；不写入仓库或模型消息，只发送到配置服务的认证请求头。自定义服务需要自行判断可信度。

发送消息后，模型可以读取授权的收藏/历史、网站上下文、来源说明、完整技术文档，以及真实净值、RT、密度、定投、对比、统计/相关/ACF和组合优化工具结果。头像与用户名不提供给模型。工具参数严格验证，净值数据不作为代码执行；调用参数、结果与图表可展开查看。不执行实盘交易、任意URL访问或个人资料写入；独立的Agent模拟运行可在用户预算内保存虚拟委托。最多12轮/32次工具调用，可停止；切换栏目继续，关闭页面即停止。不是云端常驻Agent。

对话文本保留最近60条，每条最多16000字符；工具追踪不持久化。收藏/历史及被调用的分析结果会发给用户所配置的服务，API费用由该服务计费。未提供真实API密钥时，自动化验证采用模拟模型响应，覆盖SSE分片、工具循环、失败、取消和密钥隔离；不宣称完成真实付费模型对话。


组合交互使用固定显示的权重/风险贡献比例表，大图只切换前沿、回测和RT。两个目标滑块常驻：收益目标选择前沿采样点，波动上限通过42次目标均值二分与二次规划选择不超过上限的最大样本均值解。曲线的单调三次插值仅用于视觉平滑，数值与权重仍由优化器计算。基金选择采用勾选/全选后统一确认，取消不会改动当前集合。

个人首页置顶头像资料，显示ipify提供的公网出口IP及按本机首次保留日期计算的陪伴天数。公网IP可能是代理或VPN出口，不加入Agent上下文。显示板按收藏真实近似复权净值检测单期和五期异动；滞后/旧缓存/未复权不触发预警。默认阈值3%/5%，可调；最多前30只收藏。无预警时显示当前定投模拟方案、收藏涨跌概览或用户生成的AI总结。基金不是实际持仓。

设置支持中英界面、仅清理行情缓存（保留个人数据、密钥与聊天）、阈值和API连接测试。中英切换保留基金名称、来源资料、数学公式和原始对话。每日AI总结需API已验证，用户开启后只在个人页打开时工作，不是关闭网页后的推送。Cloudflare授权、后台服务和iPhone系统推送按用户要求暂停，界面明确显示未启用。


## 虚拟持仓与全市场目录

个人首页增加与预警板同尺寸的虚拟持仓入口，二级全屏页面提供个人 / Agent 两个独立模拟账本，可同时进行。支持从今日提交单次投入、每日/每周/每月定投、累计预算、停止定投及分模式清空。记录本机保存；刷新、再次进入和北京日期变化会依据新公布净值重算，不需要重新下单。

模拟版本 `paper-1.0.0`：今日委托最早从明日起首个实际净值日买入，不能回填历史；每日仅在实际净值日投入，不补投节假日。周/月计划顺延至实际净值日，同一委托同日最多一次；月末按该月最后一日处理。使用人民币份额的近似复权指数，假设红利再投、零费用，不等同实际成交。非估值日沿用最近公布价格进行账面估值，日历标记未更新；QDII迟报按净值所属日期更新。每日盈亏扣除新增投入，回撤基于剔除投入后的链式收益指数；不是实盘资产、盘中行情或保证收益。

Agent模拟先由用户设置总预算和研究目标，再运行研究；可选网页可见期间每日一次（需API验证）。所有委托的累计承诺上限之和不得超过预算；已停止计划的额度保守保留，清空Agent模拟才重新开始预算。普通聊天可读取两套模拟及其曲线，只能由Agent模拟运行提交自身虚拟委托，不能修改个人账本；取消运行后此前已提交的虚拟委托保留。设置变更/清空会阻止旧研究任务写入新模拟。未配置真实API时不会生成虚构Agent持仓。

`search_funds`使用天天基金公开目录搜索代码、中文名称、拼音或类型，包括从未浏览/收藏的基金，再通过原有净值和分析工具研究。目录不是推荐排序或可申购清单，货币型、外币份额等仍受计算模块支持范围限制。公开可访问不代表开源许可，源授权仍须另行确认。`npm run update-catalog`与原净值任务一起定时更新目录，失败保留带原日期的快照。浏览器只读取本网站JSON；解析源脚本只提取JSON字面量，不执行上游代码。

关闭网页后的云端Agent、自动任务和iPhone系统推送仍暂停。当前自动补算在网页载入、北京日期变化、恢复可见和15分钟检查时进行；AI每日研究还需页面可见及自己的API密钥。
